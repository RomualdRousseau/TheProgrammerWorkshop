# 👋 Welcome to **The Programmer Workshop**

**Code. Learn. Build. Explore.**

This GitHub organization is the companion to the **The Programmer Workshop** YouTube channel, where programming meets curiosity.

Whether you're fascinated by low-level programming, retro computers, classic games, modern software engineering, or the latest advances in Artificial Intelligence, you'll find projects here that accompany the videos and encourage experimentation.

---

## 🎥 What You'll Find

The channel explores topics such as:

- 💻 Programming techniques and software engineering
- 🕹️ Retro gaming and game development
- 🖥️ Retro-computing, vintage hardware, and classic operating systems
- 🤖 Artificial Intelligence and modern developer tools
- ⚙️ Algorithms, systems programming, and performance optimization
- 🔬 Reverse engineering, emulation, and technical deep dives
- 🛠️ Fun side projects and coding experiments

The goal is not just to explain how things work, but to understand _why_ they work.

---

## 📂 About This Repository

This GitHub hosts the source code, examples, and experiments featured throughout the channel.

Depending on the video, you may find:

- Complete projects
- Tutorial source code
- Game prototypes
- Retro-programming examples
- AI demonstrations
- Utilities and developer tools
- Experimental ideas that didn't make the final cut

Some repositories are educational and intentionally simple, while others dive into advanced engineering topics.

## 👨‍💻 Who Is This For?

This content is designed for developers who enjoy understanding computers beyond the surface.

You might enjoy this if you're:

- A hobbyist programmer
- A professional software engineer
- A retro-computing enthusiast
- A game developer
- An embedded or systems programmer
- An AI enthusiast
- Someone who simply enjoys learning how computers really work

Whether you're writing your first emulator or experimenting with the newest LLM APIs, you're in the right place.

---

## 🎯 Philosophy

Technology changes rapidly, but good engineering principles remain.

This channel embraces:

- Learning by building
- Understanding fundamentals before frameworks
- Appreciating both vintage and modern technology
- Curiosity over hype
- Sharing knowledge openly

From 8-bit machines to AI-powered applications, every project is an opportunity to learn something new.
